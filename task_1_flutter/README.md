# 📱 Digital Business Card — Flutter

A simple and clean **Digital Business Card** built with Flutter as part of my Flutter development training.

The application displays a football player's personal and contact information in a modern business card design.

## ✨ Features

* 🎨 Clean and modern UI
* 📱 Responsive mobile layout
* 🖼️ Network Image for the player's profile picture
* 📞 Phone contact information
* 📧 Email contact information
* 👤 Username display
* 🎨 Custom colors and styling
* 🧩 Clean Code structure
* 📂 Organized project files
* 🚫 Static screen with no scrolling

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material Design**
* **Google Fonts**
* **Network Image**

## 🎯 Clean Code

The project follows a simple clean structure by separating:

* **Data** → Player information
* **Constants** → Application colors
* **Screens** → Main application screen
* **Widgets** → Reusable contact card widget
* **Main** → Application entry point

This makes the code easier to read, maintain, and reuse.

## 🖼️ UI Design

The application contains:

* Circular player profile image
* Player name and profession
* Contact information section
* Phone card
* Email card
* Username card
* Digital Business Card footer
